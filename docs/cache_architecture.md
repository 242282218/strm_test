## 命名空间定义

| 命名空间 | 用途 | 默认 TTL | 最大容量 |
|---------|------|---------|---------|
| LINK | 直链缓存 | 600s (10分钟) | 2000 |
| FILE_SIZE | 文件大小缓存 | 3600s (1小时) | 1000 |
| TMDB | TMDB API 缓存 | 86400s (24小时) | 500 |
| QUARK_API | 夸克 API 缓存 | 300s (5分钟) | 1000 |
| STRM | STRM 相关缓存 | 3600s (1小时) | 500 |
| EMBY | Emby 相关缓存 | 600s (10分钟) | 500 |
| PROXY | 代理缓存 | 600s (10分钟) | 1000 |
| RENAME | 重命名缓存 | 1800s (30分钟) | 500 |
| SCRAPE | 刮削缓存 | 3600s (1小时) | 500 |
| GENERAL | 通用缓存 | 600s (10分钟) | 1000 |

## 跨命名空间依赖关系

```
QUARK_API ──┬──> LINK ──> PROXY
            ├──> FILE_SIZE
            └──> PROXY

TMDB ───────┬──> RENAME
            └──> SCRAPE

EMBY ───────┴──> STRM
```

当源命名空间失效时，会自动级联失效所有依赖的命名空间。

## 使用方式

### 1. 统一模式 (推荐)

```python
from app.core.cache_manager import get_cache_manager, CacheNamespace

# 获取缓存管理器
cache = get_cache_manager()

# 设置缓存
await cache.set(CacheNamespace.LINK, "file_123", link_data)

# 获取缓存
link_data = await cache.get(CacheNamespace.LINK, "file_123")

# 失效缓存（自动级联）
await cache.invalidate_related(CacheNamespace.QUARK_API)
```

### 2. Legacy 模式 (兼容旧代码)

```python
from app.core.cache_manager import get_legacy_cache_adapter

# 获取适配器
cache = get_legacy_cache_adapter("link")

# 使用旧接口
await cache.set("file_123", link_data)
link_data = await cache.get("file_123")
```

### 3. 切换 Legacy 模式

设置环境变量：
```bash
CACHE_LEGACY_MODE=true
```

## 监控 API

| 端点 | 方法 | 描述 |
|-----|------|------|
| `/monitor/cache/stats` | GET | 获取全局统计 |
| `/monitor/cache/namespaces` | GET | 获取所有命名空间统计 |
| `/monitor/cache/namespace/{name}` | GET | 获取指定命名空间统计 |
| `/monitor/cache/versions` | GET | 获取所有版本信息 |
| `/monitor/cache/invalidation-log` | GET | 获取失效事件日志 |
| `/monitor/cache/invalidate/{name}` | POST | 失效指定命名空间 |
| `/monitor/cache/increment-version/{name}` | POST | 递增版本号 |
| `/monitor/cache/clear/{name}` | POST | 清空指定命名空间 |
| `/monitor/cache/clear-all` | POST | 清空所有缓存 |
| `/monitor/cache/health` | GET | 获取健康状态 |
| `/monitor/cache/dashboard` | GET | 获取仪表板数据 |
